### 更新與測試

修改 `trip.json` 後，提交至 `main` 即可由已啟用的 GitHub Pages 發布。請依 [docs/UIUX.md](docs/UIUX.md) 執行 `npm run lint:uiux`、`npm run test:uiux`、`npm run test:timeline`、`npm run test:journey`、`npm run test:places-curation`，並在瀏覽器檢查手機與桌面版。

本次自動部署成功；自訂 `Chronological Timeline Contract` 工作流程因 GitHub 未配置 runner（無 step logs）未能執行測試，**不視為驗收通過**。此版本 `trip.publication` 維持 `draft/not-run`，等待人工審查。

### 2026/11/19：景點照片與中國地圖

- 景點目錄中的 10 個獨立景點均附照片、來源與授權資訊。部分照片非冬季拍攝，另有註明；照片來自 Wikimedia Commons/Unsplash，需要可連線到原圖站台。
- 中國境內改用 **高德地圖官方免金鑰 iframe**：有景點座標時顯示單點，未知位置時只顯示有來源的區域底圖；沒有正確的起訖座標不會推算虛假的駕車路線。景點外連亦改用高德 URI。
- 本行程專用補充規範：[docs/UIUX_XINJIANG.md](docs/UIUX_XINJIANG.md)。地圖／照片只作旅途參考，具體進出路線和集合地點以領隊為準。
- 可執行 `npm run test:china-maps` 測試高德網址生成、飛行排除、不推定座標及 10 張景點照片的 metadata。
